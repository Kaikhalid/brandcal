# Security policy

brandcal is in early development (v0.x) and has no supported release yet.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/Kaikhalid/brandcal/security/advisories/new)
("Report a vulnerability" on the repository's Security tab). Do not open a public issue.

Please include a description, steps to reproduce and the affected version or commit.
You should receive an acknowledgement within a few days.
